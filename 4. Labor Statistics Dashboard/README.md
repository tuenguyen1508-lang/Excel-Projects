# Labor Statistics Dashboard  
## Wage & Employment Insights by Industry

## Overview
This project analyzes a labor statistics dataset and presents key wage and employment insights through an interactive dashboard titled:  
**“What do wage and employment figures look like by industry?”**

## Dataset
The dataset contains **6 core fields**:
- Year  
- Industry  
- State  
- Establishments  
- Employees  
- Average Annual Wage  

It spans **1,919 columns (including headers)**.

## Data Preparation
Key preparation and calculation steps included:
- Cleaning and structuring the dataset for analysis
- Filtering and validating **10 unique industries**
- Applying Excel formulas to extract and calculate metrics:
  - **IFS** for conditional logic
  - **SUMIFS** for conditional aggregation
  - **AVERAGEIFS** for conditional averages
- Calculating:
  - **Average annual wage by industry**
  - **Total employees by industry**
  - **Wage & employee trends over time**
- Building **state-level comparisons**, including:
  - Employees
  - Population
  - Employees per 1,000 residents
  - Average wages

## Dashboard Features
The dashboard is interactive and allows users to scroll/select an industry. For the selected industry, it displays:
- **Average annual wage**
- **Share of total employees**
- **Wage & employee trends over time**
- A **map by state** showing:
  - Average wages
  - Employees per 1,000 residents

## Key Insight
The **Information** industry had the **highest average annual wage**. Wages increased each year, while employment remained relatively stable over time.

## Tools & Skills Used
- Excel (IFS, SUMIFS, AVERAGEIFS)
- Data cleaning and preparation
- Trend analysis
- Interactive dashboard design
- State-level comparative analysis

# Booking Data Dashboard  
## Turning Pivot Tables into Leadership-Ready Insights

## Overview
This project transforms existing booking data (already extracted into **pivot table format**) into a clear, interactive dashboard that makes it easier to communicate key performance insights to the leadership team.

<img width="764" height="283" alt="image" src="https://github.com/user-attachments/assets/db998810-3aa1-44a9-870c-47cecd2167d2" />

## Objective
- Convert pivot table outputs into a dashboard that is easy to interpret and actionable for decision-makers
- Highlight booking and cancellation patterns that impact revenue

## Key Insights
- **Cancellations resulted in ~ $1M in lost revenue last summer**, with the biggest impact in **July and August**.
- Peak summer months generated strong revenue overall, but also showed the **highest cancellation-related revenue loss**.
- **Bookings made within 30 days of arrival** accounted for only **~17% of cancellations**.
- Same-month summer bookings maintained **lower cancellation rates**, despite having **higher average prices**.

## Recommendation
### Overbook Same-Month Resort Reservations (July–August)
Overbooking same-month reservations during peak summer can help:
- Replace advance bookings that are **more likely to be cancelled**
- Shift demand toward bookings with **lower cancellation risk**
- Capture bookings at a **higher average price**, improving revenue resilience

## Tools & Skills Used
- **Excel:** Used to transform booking pivot table outputs into a clear, leadership-ready dashboard.
- **PivotTables:** Used to summarise booking, cancellation, revenue, and seasonal performance patterns.
- **Revenue Analysis:** Used to estimate cancellation-related revenue loss and identify high-impact periods.
- **Seasonality Analysis:** Used to compare summer booking trends and identify peak revenue periods.

## Outcome
A leadership-ready dashboard that supports decision-making around summer capacity strategy and cancellation risk management.

# Excel Financial Modelling from Scratch (End-to-End)

## Overview
This project showcases my end-to-end **Excel financial modelling** practice - from building core **financial statements** and **costing models** to creating a **13-week cash flow forecast**, plus a **financial KPI dashboard** with advanced visualisations.

## Key Topics Covered
- **Financial Statement Modelling**
- **Budgeting & Forecasting**
- **Discounted Cash Flow (DCF) Analysis**
- **What-if / Scenario Analysis**
- **Project Costing Models**
- **Activity-Based Costing (ABC)**
- **Advanced Financial Techniques**
- **Excel formula tips & productivity shortcuts**

## Main Deliverable 1: 13-Week Cash Flow Forecast
Built a complete **13-week cash flow forecast model** from scratch, including:

### Data Preparation
- Cleaned and structured the **source data**
- Built a reusable **forecast template**
- Implemented **error checking** and validation rules

### Mapping & Model Logic
- Applied **conditional formatting** for quality control
- Created **transaction mapping** to standardise categories
- Built **unique IDs & categories** to support consistency and traceability
- Developed formulas to:
  - calculate history
  - generate **aging reports**
  - produce a consolidated **cash flow summary**

## Main Deliverable 2: Financial KPI Dashboard
Developed an interactive **financial KPI dashboard**, including:
- Raw data inputs and modelling layer
- KPI calculations and summary tables
- Charts that clearly communicate performance and trends

### Visualisations Included
- Trending **column chart**
- **Line chart with markers**
- **Bullet chart** (with performance targets)
- **Combo chart**
- **Stacked bar charts**
- **Four-segment line chart**

> For full details, please refer to the **two attached Excel files**.
